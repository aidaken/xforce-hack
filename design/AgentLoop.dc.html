DeepSeek V4.1 Flash over OpenRouter. The prompt bans invented facts and holds scientific terms verbatim. No key? A local heuristic still returns a remake.

Adapt
POST /api/chat
This isn’t working sends the complaint back through the same endpoint. It can switch the reading tab and re-remake from the same source.
The line that proves it is agentic
Every remake opens by naming its own format and its reason — “I chose a flowchart because…”. A template cannot write that sentence, because a template never made a choice.
One constraint worth knowing
Vercel functions are stateless, so the client holds the parsed document and resends it on every call. A documentId alone will not survive a new instance.
