How it works
04 / 09
The agent decides the shape.
We never ask the student to pick a format they have never seen.
01
Read
Split the source into atomic claims and number them. Six sentences became S1–S6. Nothing is summarised yet — this is only bookkeeping.
02
Decide
Score the material (sequential? branching? definitional?) against the learner. Branching process + high decode cost → flowchart. Same passage, low working memory → staged quest.
03
Produce
Build the artefact. Every node, step and card carries the id of the claim it came from — so the next stage has something to check against.
04
Self-check
Re-read the output against the source and answer two questions only: is anything missing, and is anything here the source never said.
05
Adapt
The student is the only judge that counts.
When Mara says “I keep losing my place”, that sentence is not a support ticket — it is a new input to Decide. The agent re-runs the choice with her complaint added to her profile, rebuilds, and re-checks against the same source. The passage never changes. The shape does.
