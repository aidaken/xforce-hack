02 / 09

Human Physiology, 8e · Ch. 12, p. 340
Thermoregulation in endotherms is maintained by a negative feedback loop. Thermoreceptors distributed in the skin and in the hypothalamus detect deviation from the body’s set point of approximately 37 °C. Afferent signals are integrated by the preoptic area of the hypothalamus, which functions as the control center for the loop. When core temperature rises above the set point, efferent signals produce vasodilation of cutaneous arterioles and activation of the eccrine sweat glands, increasing radiative and evaporative heat loss respectively. When core temperature falls below the set point, the hypothalamus initiates vasoconstriction, piloerection, and shivering thermogenesis, while the thyroid axis may be recruited to sustain nonshivering thermogenesis over longer intervals. Because the corrective response in each case opposes the initial deviation rather than amplifying it, the loop is self-limiting: as core temperature returns toward the set point, receptor firing diminishes and the effector response is progressively withdrawn.

How it works
04 / 09
The agent decides the shape.
We never ask the student to pick a format they have never seen.
01
Read
Split the source into atomic claims and number them. Six sentences became S1–S6. Nothing is summarised yet — this is only bookkeeping.
02
Decide
Score the material (sequential? branching? definitional?) against the learner. Branching process + high decode cost → flowchart. Same passage, low working memory → staged quest.
03
Produce
Build the artefact. Every node, step and card carries the id of the claim it came from — so the next stage has something to check against.
04
Self-check
Re-read the output against the source and answer two questions only: is anything missing, and is anything here the source never said.
05
Adapt
The student is the only judge that counts.
When Mara says “I keep losing my place”, that sentence is not a support ticket — it is a new input to Decide. The agent re-runs the choice with her complaint added to her profile, rebuilds, and re-checks against the same source. The passage never changes. The shape does.

When the student says it isn’t working.
M
Mara, 12 minutes in
“I keep losing my place.”
What the agent reads that as
A re-entry failure — not “too hard”, not “too long”, not “wrong format”. The shape was right. The state was not being held for her.
Getting this wrong is the whole risk. An agent that hears “this isn’t working” and just simplifies everything will eventually simplify the content away.
What changed on the rebuild
Format
Staged quest → staged quest. Unchanged — the complaint was not about the format.
Steps on screen
Six visible, one active → one visible. The rest collapse behind the progress bar.
Added
A one-line recap of the step she finished last, pinned above the live step, so coming back costs nothing.
Removed
The XP counter. It was competing with the position marker for the same attention — gamification that works against the learner is just noise.
Re-checked
6 of 6 source claims still present. 0 invented. The rebuild ran through the same check as the first draft — adapting to a student never costs fidelity to the text.

Why it matters
08 / 09
Accessibility tools ask the student to keep reading the same shape, harder.
One shape fits nobody
Larger type and text-to-speech help, and every student gets the same one. Devon and Mara need opposite things from the same paragraph — and neither of them needs a bigger font.
The student is the signal
Nobody has to name their diagnosis or fill in a learning-style quiz. Saying “this isn’t working” is the whole interface, and the agent has to do something specific with it.
Traceable enough to assign
An instructor will not hand a class an AI rewrite of the textbook they are examined on. Claim-level tracing is what makes this adoptable instead of a novelty.
The text stays exactly as authoritative as it was. Only the way in changes.
