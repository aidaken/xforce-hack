# Problem Statement

[2] Generative AI Neurodiversity-Adaptive Study Workspace
Develop an AI-driven tool that dynamically restructures academic textbooks or technical documentation into visual flowcharts, checklists, or gamified summaries tailored for ADHD or dyslexic learning styles. Extend it with agentic capability where the agent should decide which restructuring fits the material and the learner, produce it, check its own output against the source, and adapt when the student says it isn’t working.

## Datasets & resources
- Academic textbook: 3 complex paragraphs from an OpenStax Biology chapter (e.g., Cellular Respiration), https://openstax.org/
- Technical documentation: AWS IAM Policy evaluation logic (here) or the React useEffect reference (here)
- Dense STEM concept: OpenStax Calculus Vol. 1, §3.6 The Chain Rule (here) or University Physics Vol. 2, §6.3 Applying Gauss's Law (here)

## Demonstration Goals
Show the judges:
- The same passage rendered two different ways for two different learners
- A human teammate’s side-by-side check against the source showing nothing was lost or invented
