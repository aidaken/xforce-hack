# Workflow

1. Each team member works on their personal branch (named after them).
2. When ready, open a Pull Request from your personal branch to `dev`.
3. After review and approval, merge into `dev`.
4. The `dev` branch is then merged into `main` (by designated integrators or after team consensus).

## Branch Naming
- Personal branches: lowercase, hyphen-separated (e.g., `ahmad-mashhood`)
- `dev`: integration branch
- `main`: stable/release branch
